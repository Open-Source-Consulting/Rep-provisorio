# Documentação do JOVI AI

Este diretório contém o contexto da entrega e as instruções para continuar o projeto.

- [ATT.md](ATT.md) — enunciado da Sprint 4 fornecido pela equipe; fonte dos requisitos acadêmicos.
- [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) — produto, estrutura do código, o que funciona e o que é conceito, limites conhecidos.
- [REQUIREMENTS.md](REQUIREMENTS.md) — requisitos do enunciado mapeados ao estado atual e pontos a concluir.
- [API.md](API.md) — API definida com a equipe (MockAPI, recurso `Receitas`): endereço, schema, testes, operações, rotas, hooks, login de demonstração e seed.
- [HANDOFF.md](HANDOFF.md) — resumo para o integrante que vai escrever o README final e publicar na Vercel: comandos, configuração, credenciais e pendências.
- [CLAUDE_PROMPT.md](CLAUDE_PROMPT.md) — pedido de trabalho usado para a implementação da Sprint 4.
- [legado-sprint3/](legado-sprint3/) — a versão estática da Sprint 3 (HTML, CSS, JS e fontes antigas), guardada como referência.

Na raiz: [PRODUCT.md](../PRODUCT.md) resume o produto e as decisões de marca, e o [README](../README.md) é o arquivo de entrega (ainda da versão estática; será reescrito pelo responsável, ver HANDOFF).

Mantenha cada fato em um só lugar: use `ATT.md` para o enunciado, `PROJECT_CONTEXT.md` para o estado do produto, `API.md` para a API e `REQUIREMENTS.md` para o acompanhamento da Sprint.
